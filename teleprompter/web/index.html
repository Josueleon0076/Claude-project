🎬 Teleprompter

Ajustes de lectura

Controles durante la lectura: toca la pantalla para pausar o continuar · arrastra para moverte · teclado/control Bluetooth: Espacio, Enter o AvPág = pausa · RePág o ← = retroceder · ↑/↓ = velocidad. En la APK de Android: Volumen + = pausa, Volumen − = retroceder.
Deja una línea en blanco entre párrafos. Escribe indicaciones entre corchetes, como [PAUSA], [SONRÍE] o [MOSTRAR PRODUCTO]: se ven en amarillo y no cuentan como palabras.
Toca la pantalla para leer · toca otra vez para pausar
